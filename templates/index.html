    About the Project

    This mini-project uses the public Kaggle Crop Recommendation Dataset (2,200 records, 22 crops). Data is preprocessed with Pandas, split 80/20 into training and testing sets, and a Scikit-learn Random Forest Classifier is trained. A Flask backend serves predictions to this page.
